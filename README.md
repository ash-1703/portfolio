# Aishwarya — Portfolio (Next.js + Tailwind, Cyan Gradient Theme)

## Quick start
1) Install deps
```bash
npm install
```
2) Run locally
```bash
npm run dev
```
3) Build & start
```bash
npm run build && npm start
```

## Notes
- Theme uses cyan/teal gradient (`brand` color in Tailwind config).
- Your portrait is under `public/images/aishwarya.jpg` and used in the Hero and About sections.
- Edit content in:
  - `app/page.tsx` (home + projects + contact)
  - `app/about/page.tsx` (bio/skills)
  - `components/ProjectCard.tsx` for project cards
  - `styles/globals.css` & `tailwind.config.ts` for theme tweaks
